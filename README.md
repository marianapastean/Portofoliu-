# Mariana Păștean — portofoliu

Site static (HTML, CSS, JS), fără build. Deschide `index.html` sau publică pe GitHub Pages.

**Date de contact:** completează `CONTACT` în partea de sus a `script.js` (email și linkurile social media).

**Publicare:** GitHub → Settings → Pages → Branch `main`, folder `/ (root)`.

**Imagini proiecte:** `assets/p/` (social-*, logo-*, landing-*, grafic-*). Pentru calitate maximă, înlocuiește fișierele cu originalele, păstrând numele.
